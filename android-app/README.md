# Tape Control (Android, Kotlin)

Нативний Android-пульт для BLE-пристрою **TapeControl** (ESP32). Логіка і вигляд — як у веб-версії.
Мова: Kotlin + Jetpack Compose. Мінімальна версія Android — 8.0 (API 26).

## Як зібрати APK на GitHub

1. Створіть **приватний** репозиторій на GitHub і завантажте в нього весь вміст цієї папки
   (разом з прихованою папкою `.github` та папкою `keystore`).
2. Відкрийте вкладку **Actions** → зліва **«Збірка APK»** → **Run workflow**.
   Галочка «Створити GitHub Release» увімкнена за замовчуванням.
3. Через 4–6 хвилин APK буде:
   - у розділі **Releases** репозиторію (файл `TapeControl-1.0.N.apk`) — найзручніше качати з телефона;
   - а також як артефакт запуску (zip, зберігається 30 днів).
4. Завантажте APK на телефон і встановіть (дозвольте встановлення з невідомих джерел для браузера/файлового менеджера).

Кожна нова збірка має більший номер версії й той самий підпис, тому встановлюється **поверх** попередньої без видалення.

## Перший запуск на телефоні

- Натисніть **CONNECT** і дайте дозволи на Bluetooth («Пристрої поблизу»).
- Android 11 і старіше: потрібна ще увімкнена **геолокація** (вимога системи для пошуку BLE).
- Пристрій має рекламуватись під назвою `TapeControl` (або з сервісом `12345678-1234-1234-1234-123456789abc`).

## Що виправлено порівняно з веб-версією

- **Автоперепідключення** при обриві зв'язку (до 5 спроб), перші спроби — напряму за адресою, без пошуку.
- **Черга команд**: швидкі натискання не губляться й не дають помилку «операція вже виконується».
- **MTU 247** і складання JSON зі шматків: довгий статус більше не обрізається та не ігнорується мовчки.
- Після підключення **одразу читається поточний стан** (якщо прошивка дозволяє читання).
- Таймаути на пошук, підключення й налаштування; коректне закриття GATT (щоб ESP32 не «зависав» підключеним).
- Кнопка під час пошуку/підключення стає **CANCEL**; повторні натискання CONNECT не створюють дублів.
- Не дублюється запис «Відключено» в логу; режими приймають значення 0/1, true/false.
- Підключення не рветься при повороті екрана (BLE живе у ViewModel).

## Файли

- `app/src/main/java/com/tapecontrol/app/ble/TapeBleClient.kt` — уся робота з BLE.
- `.../ble/TapeStatus.kt` — стан пристрою та розбір JSON.
- `.../ui/TapeScreen.kt` — екран (копія вигляду веб-версії), `.../ui/Theme.kt` — кольори й шрифти.
- `.github/workflows/build-apk.yml` — ручна збірка в Actions.
- `keystore/tapecontrol.jks` — ключ підпису (репозиторій приватний, пароль у `app/build.gradle.kts`).

Шрифти Orbitron і Share Tech Mono завантажуються під час збірки в Actions. Якщо не вдасться — застосунок
використає системні шрифти й усе одно працюватиме.
