# ble_wifi_control — Pioneer CT-737 VFD

Контролер касетного магнітофона на ESP32-S3

**Pioneer CT-737 VFD · Версія прошивки: v12.80**

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## Можливості

- **Керування VFD** — оригінальний дисплей Pioneer CT-737 через 3 мікросхеми зсувних регістрів (72 біти)
- **VU метр** — індикатор рівня в реальному часі на VFD (16 сегментів на канал, пікова затримка)
- **OLED дисплей** — 128×64 з 14 стилями відображення (Sd00–Sd13): спектр, VU, осцилограф, гоніометр, бобіни, очі
- **PCM1808 I2S АЦП** — зовнішній стерео АЦП 24 біт, без шумів, без дільників сигналу
- **FFT аналізатор спектру** — 512 семплів, 44100 Гц, 16 логарифмічних смуг 200–14000 Гц (Core 0)
- **Транспорт** — соленоїди PLAY / STOP / REWIND / FORWARD (імпульс 900 мс)
- **Лічильник стрічки** — імпульсний лічильник з підтримкою від'ємних значень та формату HH:MM
- **Tape Return** — подвійний клік: автоматичне повернення на нуль лічильника
- **Remain** — потрійний клік: нескінченний повтор пісні (автовизначення початку і кінця)
- **PCF8574** — зчитування стану транспорту (PLAY/PAUSE/FWD/REC/REW) і типу стрічки
- **WiFi + WebSocket** — веб-інтерфейс (tape.local) з живим VU метром
- **BLE GATT** — дистанційне керування через Chrome Android (TapeControl_BLE.html та APK)
- **MQTT + Home Assistant** — авторозпізнавання всіх об'єктів
- **OTA** — оновлення прошивки по WiFi з Arduino IDE (ім'я хоста: `TapeDeck`)
- **ІЧ приймач** — протокол NEC, прив'язка до 3 кодів на команду
- **WS2812B** — LED стрічка 40 світлодіодів з анімацією спектру
- **Enкодер** — навігація меню: клік / подвійний / потрійний клік / довге натискання
- **FreeRTOS** — двоядерний: Ядро 0 = WiFi/BLE/MQTT/FFT, Ядро 1 = VFD/OLED/соленоїди/енкодер

## Налаштування Arduino IDE

> ⚠️ **ВАЖЛИВО: без правильних налаштувань веб-інтерфейс не працюватиме (недостатньо пам'яті heap)!**

| Параметр | Значення |
|----------|---------|
| Board | ESP32S3 Dev Module |
| Upload Speed | 921600 |
| CPU Frequency | 240MHz (WiFi) |
| Flash Mode | QIO 80MHz |
| Flash Size | **8MB (64Mb)** |
| **PSRAM** | **QSPI PSRAM** ← обов'язково! |
| Partition Scheme | 8M with spiffs (3MB APP/1.5MB SPIFFS) |
| Core Debug Level | None |

**Чому QSPI PSRAM обов'язковий:** ESP32-S3 N8R2 має 2 МБ PSRAM. Веб-сторінка займає ~20 КБ і не поміщається в heap через фрагментацію. Без PSRAM — білий екран або "Low memory". З PSRAM — веб-інтерфейс повністю працює.

**OTA (завантаження по WiFi):** після першого прошивання через USB плата з'являється в Arduino IDE як мережевий порт з іменем **`TapeDeck`**.

## Налаштування підключення

Відредагуйте параметри на початку файлу `ble_wifi_control_v12_80.ino`:

```cpp
#define WIFI_SSID     "назва_вашої_мережі"
#define WIFI_PASSWORD "пароль_wifi"
#define MQTT_SERVER   "192.168.1.x"   // IP адреса Home Assistant
#define MQTT_PORT     1883
#define MQTT_USER     "користувач_mqtt"
#define MQTT_PASSWORD "пароль_mqtt"
```

Після першого завантаження налаштування також доступні через веб-інтерфейс (tape.local → вкладка Мережа).

## Веб-інтерфейс (tape.local)

Доступний за адресою `tape.local` або за IP адресою пристрою. Складається з 4 вкладок.

### Вкладка Керування
| Елемент | Опис |
|---------|------|
| Транспорт (іконки) | Індикатори поточного стану: REW/STOP/PLAY/PAUSE/FWD |
| PLAY / STOP / REW / FWD | Кнопки керування — імпульс 900 мс на соленоїд |
| Dolby | Перемикання Вимк → B → C → B+C |
| MPX фільтр | Вмик/вимик |
| VU метр | Рівень L та R каналів в реальному часі (WebSocket) |
| Лічильник | Поточне значення лічильника стрічки |

### Вкладка Меню
Акордеон з групами: **VFD**, **OLED**, **LED**. Налаштування змінюються слайдерами. Кнопка «Зберегти» записує у Flash.

### Вкладка IR
Прив'язка кодів ІЧ пульта до команд (PLAY/STOP/REW/FWD/Dolby). До 3 кодів на команду.

### Вкладка Мережа
WiFi (SSID, пароль, статична IP), MQTT налаштування, OTA оновлення прошивки (.bin файл через браузер).

## VFD Меню

Навігація енкодером:
- **Довге натискання (>2с)** — вхід/вихід з меню (зі збереженням)
- **Поворот** — вибір групи / зміна значення
- **Одиночний клік** — вхід в групу / наступний пункт
- **Подвійний клік** — наступна група

### Група VFD (VFd)
| Код | Назва | Діапазон | Опис |
|-----|-------|----------|------|
| SC | Scale | 0–2 | Шкала: 0=стандарт, 1=розтягнута, 2=пікова |
| Vi | Views | 1–4 | Режим відображення VFD |
| Pu | Pulses | 1–20 | Імпульсів на оберт котушки |
| An | Anim Peaks | 1–6 | Анімація піків (1=падіння, 2=відскок, 3=вгору, 4=стоп, 5=скид, 6=авто) |
| PH | Peak Hold | 0–40 | Утримання піку (×100 мс, 0=вимк) |
| rS | Release | 1–99 | Швидкість спаду зеленого VU (%) |
| rE | Red Release | 1–99 | Швидкість спаду червоного VU (%) |
| Gn | Gain | 1–200 | Підсилення сигналу для VFD |
| br | Brightness | 1–15 | Яскравість підсвічування VFD |
| SL | Silence | 0–40 | Поріг тиші (×10 одиниць) |
| Ar | ARU | 0–3 | Рівень ARU (0=вимк) |
| CA | Calibrate | — | Автокалібрування Gain |
| bL | Balance | -5..+5 | Баланс каналів (крок 0.5 дБ) |

### Група OLED (OLEd)
| Код | Назва | Діапазон | Опис |
|-----|-------|----------|------|
| Sd | Spec Style | 0–13 | Стиль OLED (0A=авто, 2A=авто без захоплення бобінами) |
| At | Auto Time | 2–10 | Час авто-зміни стилю (секунди) |
| OL | OLED Thresh | 0–16 | Поріг перемикання OLED режимів |
| SG | Spec Gain | 1–99 | Підсилення спектру (×20) |
| Ob | OLED Bright | 0–99 | Яскравість OLED |
| тип | OLED Type | 0–1 | 0=SSD1306, 1=SH1106 |
| rot | Rotate | 0–1 | 0=норм, 1=перевернутий |
| Pb | Peaks | 0–3 | Піки: 0=вимк, 1=падіння, 2=вгору, 3=стоп |
| Sb | Standby | 0–20 | Вимкнення дисплеїв після N хвилин тиші (0=вимк) |

| Код | Назва | Діапазон | Опис |
|-----|-------|----------|------|
| C1 | Color 1 | 0–99 | Колір LED під час відтворення (Hue) |
| C2 | Color 2 | 0–99 | Колір LED під час запису (Hue) |
| Lb | LED Bright | 0–99 | Яскравість LED стрічки |

### Група BiiP (BiiP)
| Код | Назва | Опис |
|-----|-------|------|
| bS | Biip Start | Звук при запуску (0=вимк, 1=увімк) |
| bP | Biip Out | Звуки поза меню (tape return, remain, енкодер) |
| bn | Biip Menu | Звуки навігації в меню |
| bu | Biip Web/BLE | Звуки кнопок веб-інтерфейсу та BLE |

### Управління поза меню
| Дія | Функція |
|-----|---------|
| Одиночний клік | Скидання лічильника в 0 |
| Подвійний клік | Вмик/вимик режиму Tape Return |
| Потрійний клік | Вмик/вимик режиму Remain |
| Поворот | Перемикання Dolby (Вимк/B/C/B+C) |
| Кнопка + поворот | MPX фільтр (тільки в режимі REC) |
| Поворот в REC | Source/Tape монітор: ліво=Source, право=Tape |

## Режими Tape Return та Remain

### Tape Return (подвійний клік)
Автоматичне повернення стрічки на нуль лічильника.

| Крок | Стан | Індикатор | Опис |
|------|------|-----------|------|
| 1 | Активація | Швидке моргання | Лічильник скидається в 0. |
| 2 | Очікування нуля | Швидке моргання | Стрічка перемотується. |
| 3 | Нуль перетнуто | Повільне моргання 10 разів | STOP, потім 10 повільних миготінь. |
| 4 | Вимкнення | Не світиться | Повторний подвійний клік вимикає. |

### Remain (потрійний клік)
Нескінченний повтор пісні: автовизначення початку і кінця за рівнем сигналу.

| Крок | Стан | Індикатор | Опис |
|------|------|-----------|------|
| 1 | Активація | Швидке моргання | Лічильник скидається в 0. |
| 2 | Очікування звуку | Швидке моргання | Чекає 3с безперервного звуку. |
| 3 | Відтворення | Постійно | Аналіз сигналу, очікує паузи 2.5с. |
| 4 | Перемотка | Повільне моргання | REWIND до нуля лічильника. |
| 5 | Зупинка | Повільне моргання | STOP, пауза 2с. |
| 6 | Запуск | Швидке моргання | PLAY, цикл повторюється. |

## Режими тиші та Standby

- **Детектор тиші** — аналізує рівень L/R. Поріг SL (VFD меню) / OL (OLED). Гістерезис 500 мс.
- **Mute індикатор** — VFD chip 3, bit 2. Мигає при тиші (цикл 1с).
- **Очі (Sd05)** — при падінні сигналу нижче порогу OL замість спектру відображаються анімовані очі.
- **Бобіни (Sd06)** — пріоритетний режим. При будь-яких імпульсах лічильника — OLED переходить в бобіни незалежно від активного стилю.
- **Standby** — вимкнення VFD + OLED після N хвилин тиші (Sb=01–20). При появі сигналу — миттєве вмикання.

## Інтеграція з Home Assistant

### MQTT авторозпізнавання
Прошивка публікує повідомлення авторозпізнавання при запуску. Всі об'єкти з'являються автоматично під пристроєм **"Tape Deck"**.

**Кнопки транспорту:**
- `button.tape_deck_tape_play`
- `button.tape_deck_tape_stop`
- `button.tape_deck_tape_rew`
- `button.tape_deck_tape_fwd`

### Картка Lovelace (akai-tape-card.js)
1. Скопіювати `akai-tape-card.js` до `/config/www/`
2. HA → Налаштування → Панелі → Ресурси → додати `/local/akai-tape-card.js` (тип: JavaScript модуль)
3. Додати картку: `type: custom:akai-tape-card`
4. Зробити жорстке оновлення браузера / очистити кеш у мобільному додатку HA

## BLE дистанційне керування

### Android додатки

Доступні два APK-варіанти:

| Файл | Стек | Розмір | Версія |
|------|------|--------|--------|
| `TapeControl-kotlin-1.0.1.apk` | **Kotlin + Jetpack Compose** (рекомендовано) | 5 MB | 1.0.1 |
| `TapeControl-release.apk` | Flutter | 18 MB | — |

**Встановлення:**
1. Дозволити встановлення з невідомих джерел
2. Встановити APK
3. Відкрити і натиснути **CONNECT**

**Можливості:** REW/STOP/PLAY/FWD, стан (REC/DOLBY/MPX/HX PRO), IR активність, лог.

Вихідний код Kotlin-додатку знаходиться в папці [`android-app/`](android-app/).

### Веб-інтерфейс BLE
Відкрити `TapeControl_BLE.html` у **Chrome на Android** (Chrome на ПК не підтримує Web Bluetooth).

Індикатори оновлюються через BLE NOTIFY кожні 50 мс. Файл можна зберегти на телефон і відкривати локально.
